# Sunbriar 1.0 TEST
Native Java/Canvas Android 8+ Moon-or-Sun alternating-symbol room-loop puzzle.

Draw one non-crossing loop between cell centers. Visit each room in one continuous stretch, entering and leaving it only once. In each room visit all suns or all moons, never both kinds. Chosen symbol types alternate from room to room around the loop. Tap halfway between neighboring centers to add or remove an edge. Twelve unique symbol boards have twelve distinct loops on one shared 4x4 layout of four rectangular rooms.

Saved sky palette and room labels, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, requested permissions or account. Settings and completion marks stay on device. External studio link opens browser.
